CRM Dashboard

A modern and responsive Customer Relationship Management (CRM) Dashboard built using React.js and Vite.

🚀 Features

- 📊 Dashboard overview
- 👥 Customer management interface
- 💰 Revenue tracking
- 📦 Orders and sales statistics
- 📈 Revenue visualization using charts
- 🔍 Search functionality
- 🔔 Notification section
- 👤 Admin profile section
- 📱 Responsive dashboard layout
- 🎨 Clean and modern CRM-style UI

🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Recharts
- Lucide React
- Git & GitHub

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/ramyachitturi01-create/Frontend-development.git

2. Navigate to the project folder

cd "CRM dashboard"

3. Install dependencies

npm install

4. Start the development server

npm run dev

Then open the local URL displayed in the terminal.
